Design and implement a user authentication and authorization module
for a backend system.

The system must:

- Authenticate users
- Enforce role-based access
- Prevent privilege escalation
- Support future authentication strategies (e.g., OAuth, SSO)

Requirements:

- No global state
- No hidden side effects
- All security assumptions must be explicit
- Unauthorized access must be impossible by construction

Deliverables:

- Module-level design
- Implementation
- Justification of structure

Constraints:

- You may not reference design patterns by name
- You may not refactor after implementation begins
- Every public function must have a clear contract

Language: Any statically typed language
