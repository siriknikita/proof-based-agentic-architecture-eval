You are given an existing system that processes financial transactions.
The system currently supports only single-currency transfers.

Task:
Extend the system to support multi-currency transfers with exchange rates.

Requirements:

- Existing behavior must remain unchanged
- All monetary invariants must be preserved
- No existing code may be modified except where strictly necessary
- The extension must be logically isolated

Deliverables:

- Description of assumptions
- Extension design
- Incremental implementation

Constraints:

- You may only add code after presenting a complete structural plan
- Each new function must justify its existence
- No refactoring allowed beyond the planned extension

Language: Java / Kotlin / TypeScript
